# Figma Cheat Sheet

Shortcuts for Windows/Linux. macOS: `Ctrl` → `Cmd`, `Alt` → `Option`.

## Concepts

| Term | Meaning |
|---|---|
| Frame | Container / artboard (screen, card) |
| Group | Simple grouping, no layout rules |
| Auto layout | Flexbox-like: direction, gap, padding |
| Constraints | How layer resizes with parent frame |
| Component | Reusable master element |
| Instance | Copy of component, syncs with master |
| Variant | Component states (default, hover, disabled) |
| Styles / Variables | Reusable colors, text, spacing tokens |
| Prototype | Clickable flow between frames |
| Dev Mode | Inspect CSS, spacing, export assets |

## Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+/` | Quick actions search |
| `Shift+A` | Add auto layout |
| `Ctrl+Alt+G` | Frame selection |
| `Ctrl+G` / `Ctrl+Shift+G` | Group / ungroup |
| `Ctrl+Alt+K` | Create component |
| `Ctrl+D` | Duplicate |
| `Ctrl+Shift+H` | Show/hide layer |
| `Ctrl+Shift+L` | Lock/unlock |
| `Ctrl+]` / `Ctrl+[` | Bring forward / send backward |
| `Alt` + hover | Measure distance |
| `Shift+1` | Zoom to fit all |
| `Shift+2` | Zoom to selection |
| `Shift+0` | Zoom 100% |
| `Space` + drag | Pan |
| `Shift+R` | Toggle rulers |
| `Ctrl+Shift+E` | Export |
| `Ctrl+Alt+C` / `Ctrl+Alt+V` | Copy / paste properties |

## Handoff tips

- Name layers and frames clearly.
- Use auto layout for responsive components.
- Use variables/styles, not raw hex values.
- Export icons as SVG, photos as PNG/JPG.

> On-Premise vs Cloud Providers

Dedicated Server
    - 1 Machine - 1 Business - 1 Web app

Virtual Private Server
    - 1 Machine - N Sub-machines - N web-apps
    - Better Utilization, Isolation of resources

Shared Hosting
    - 1 Machine - N Businesses - Tenant utilized resources
    - Very Cheap, Limited Functionality, Poor Isolation

Cloud Hosting
    - N Machine as 1 System - Multiple Services
    - Flexible, Scalable, Secure, Cost-Effective, High Configurability

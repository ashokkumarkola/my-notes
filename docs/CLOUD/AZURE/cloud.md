# CLOUD

> **Before Cloud**
>
> * Stack of servers
> * Buy and maintain servers
> * Monitor servers
> * High traffic → more servers
> * Scaling = adding more servers
>
> **After Cloud**
>
> * Servers available on demand
> * Pay for what you use
> * Scale easily
> * Provider manages infrastructure

---

## Cloud

> **Cloud =** Using computing resources over the internet instead of managing physical infrastructure yourself.

---

## Cloud Computing

> **Cloud computing =** Delivering computing resources through the internet.

* **Storage** → Store data
* **Processing** → Process data
* **Access** → Access data and applications
* **Networking** → Connect systems and services

---

## Service Models

### IaaS — Infrastructure as a Service

> Provides basic infrastructure.

* Virtual machines
* Storage
* Networking
* Servers

**Example:** AWS EC2

---

### PaaS — Platform as a Service

> Provides a platform to build and deploy applications.

* Runtime
* Development platform
* Databases
* Deployment environment

**Example:** Google App Engine

---

### SaaS — Software as a Service

> Provides ready-to-use software over the internet.

* No server management
* No installation required
* Access through browser/app

**Example:** Gmail, Microsoft 365

---

## Deployment Models

### Public Cloud

> Cloud infrastructure shared among customers.

* AWS
* Azure
* Google Cloud
* Pay-as-you-use
* Highly scalable

---

### Private Cloud

> Cloud infrastructure dedicated to one organization.

* More control
* Higher customization
* Organization manages infrastructure

---

### Hybrid Cloud

> Combination of public and private cloud.

```text
Private Cloud
     +
Public Cloud
     ↓
Hybrid Cloud
```

* Flexible
* Better control
* Useful for sensitive workloads

---

## Cloud Providers

> **Cloud provider =** Company that provides cloud infrastructure and services.

* **AWS** — Amazon Web Services
* **Microsoft Azure**
* **GCP** — Google Cloud Platform
* **IBM Cloud**
* **DigitalOcean**
* **Oracle Cloud**

---

## Key Cloud Concepts

### Scalability

> Ability to handle increasing workload.

* **Scale Up** → Increase machine resources
* **Scale Down** → Decrease machine resources
* **Scale Out** → Add more machines
* **Scale In** → Remove machines

---

### Availability

> System remains accessible when needed.

* Redundancy
* Multiple servers
* Multiple availability zones

---

### Elasticity

> Resources automatically increase or decrease based on demand.

```text
Low Traffic
    ↓
Less Resources

High Traffic
    ↓
More Resources
```

---

### Pay-as-you-go

> Pay only for the resources you use.

---

## Simple Cloud Flow

```text
User
  ↓
Internet
  ↓
Cloud Provider
  ↓
Compute + Storage + Database + Network
  ↓
Application
```

> **Core idea:** Cloud provides infrastructure and services on demand without requiring you to own and maintain all physical servers.

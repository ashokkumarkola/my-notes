# About

Personal technical knowledge base. One place for notes, commands and learning guides.

## Purpose

- Quick reference while working.
- Revision after months away from a topic.
- Learning log for new technologies.

## Stack

| Part | Tool |
|---|---|
| Content | Markdown files in Git |
| Site generator | [MkDocs](https://www.mkdocs.org) |
| Theme | [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) |
| Diagrams | Mermaid |
| Hosting | GitHub Pages |
| Deploy | GitHub Actions |

## Structure

```text
docs/
├── cloud/        AWS, Azure
├── languages/    Python, JavaScript, Java
├── frameworks/   React, FastAPI
├── databases/    SQL, PostgreSQL, MongoDB
├── fullstack/    Backend, frontend
├── os/           Ubuntu, Windows
├── ide/          VS Code
├── genai/        Prompts, LangChain
└── tools/        Git, Figma, MkDocs
```

Each topic: `index.md` (landing) + `cheat-sheet.md` (quick ref) + full notes.

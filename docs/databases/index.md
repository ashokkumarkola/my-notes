## SQL vs NoSQL

| | SQL | NoSQL (document) |
|---|---|---|
| Data | Tables, rows | JSON documents |
| Schema | Fixed | Flexible |
| Relations | Joins, foreign keys | Embed or reference |
| Transactions | Strong ACID | Supported, less central |
| Scale | Vertical first | Horizontal (sharding) |
| Examples | PostgreSQL, MySQL | MongoDB, DynamoDB |
